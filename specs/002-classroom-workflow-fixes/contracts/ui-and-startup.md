# 介面與開發啟動契約

## 啟動

- `npm run dev` 從套件根執行 `node scripts/dev.mjs`。入口先執行既有 TypeScript 編譯器產出後端，再呼叫共用啟動模組，API 成功後才以 Vite `createServer` 啟動前端；終端提供可開啟的前端位址。
- 共用模組載入根目錄 `.env`，已存在的 process.env 優先；沒有檔案且必要外部設定完整可啟動。只忽略 `ENOENT`，其他讀取錯誤須報告。
- 必要設定為 `TEACHER_PASSWORD`。`GOOGLE_SERVICE_ACCOUNT_JSON` 選填，`PORT` 未填預設 3000，提供時須為 1 至 65535 的整數。Google 設定提供但無效時明確報錯，不輸出 JSON 或金鑰。`GROUP_CODES_JSON` 完全不讀取，連錯誤舊值都不能阻止啟動。
- Vite 的根仍是 frontend，envDir 設為專案根；代理只使用已驗證 API 連接埠。禁止把教師密碼或 Google 金鑰放入 VITE_、define 或公開 config。
- 編譯、必要設定、API 連接埠或 Vite 啟動失敗時退出非零並關閉已開服務。SIGINT／SIGTERM 統一關閉 Vite、API、等待中請求及編譯子程序，不遺留占用連接埠。
- Vite 熱更新不重建活動。後端或 `.env` 修改須手動重啟入口，重啟建立空白新活動。正式流程保留 `npm run build` 及 `npm start`，共用同一設定規則，不在正式啟動時啟動 Vite。

## 登入與恢復

教師頁面顯示「教師密碼」；學生頁面顯示「加入碼」「名稱」。標籤與 input 關聯，必填及錯誤有可讀文字；錯誤使用 `role="alert"`，載入／重連狀態可用 `role="status"`。切換角色清空先前輸入與錯誤，不能將教師密碼帶入學生欄。輸入名稱、組名、檔名與答案僅以 React 文字呈現。

依憲章 2.0.0，學生已驗證後才將本組加入碼及本人恢復資料存於該分頁 sessionStorage，不能取得或保存全班碼表。重新整理時先顯示「正在恢復加入狀態」，完成伺服器重新驗證後才顯示姓名、組名及快照；網路不可用顯示「連線中斷，正在重新連線」，保留可重試狀態。得知 401／活動過期／撤權時清暫存並保留可理解原因，回到加入頁。學生登出只清本分頁資料，不刪老師名單。關閉後另開全新分頁可重新輸入相同加入碼及名稱接回。

App 以登入操作序號及 AbortController 管理登入／恢復。登出、切換角色或啟動另一次登入時，使先前登入、恢復、輪詢與名單請求全部失效；任何晚回應都不得重新寫入 session、sessionStorage 或舊角色資料。只中止 fetch 不足以保證安全，套用回應前仍要比對目前操作序號。

同分頁只有 App 擁有一個 `useActivityView` 輪詢，將 view、連線狀態與動作傳給 TeacherRound／StudentRound／名單及預覽，避免各元件重複輪詢。老師名單隨 rosterVersion 更新；學生送答與重連讀取使用同一個已驗證 session。送答不自動重試，畫面斷線時保留草稿並提示；伺服器確認已收後以已收答案為準。

教師重新整理可重新輸入密碼恢復同活動，後端名單與來源不能清空；本次不自動儲存教師密碼。學生分頁暫存被瀏覽器禁止時，提示「此瀏覽器無法保留加入狀態，重新整理後請重新輸入加入碼與名稱」，本次仍可登入及斷線重連。

## 老師名單

空名單顯示組名輸入與「新增組別」。新增、更名、刪除為獨立操作，提交時停用該動作；不能把加入碼或組別 ID 當作新增必填值。刪除前可以確認組名，避免誤刪已加入組，確認內容不洩漏其他組碼。清單每組顯示組名、加入碼及本活動曾加入的學生名稱，不標示或推算在線狀態。

首回合開始後繼續顯示組名、加入碼及成員，僅停用名單修改。不能像目前 Roster 一樣在 locked 分支只顯示提示而隱藏整份名單。學生稍後加入仍更新老師的曾加入名單。

老師首回合前更名成功後，已登入學生以最新快照顯示新組名，不必重新登入；加入碼、原成員與已填草稿不因更名被清除。

移除 availableGroups、可用組別 ID 下拉選單、環境預設碼說明及全量「儲存名單」流程。各種無效輸入維持已保存資料，不清除使用者可修正的組名輸入。

## 學習單

老師可選「線上試算表」或「本機 XLSX」。本機有標示 10 MiB 的選檔入口，不要求 Google 設定；預覽顯示所選檔名／工作表、主題數、填空數、回合數及完整題號。多工作表的下拉選擇保留，移除需求僅指組別下拉選單。

多頁候選尚未確認時，保留目前有效學習單及舊選題；顯示候選屬於待匯入檔案，不把它標成已套用。檔案及選擇只保留於目前匯入操作，載入中避免重複提交。驗證未通過或發布前被拒絕時指出原因及修正方式且不變更已發布資料；成功更換後清除舊選題與準備回合，不自動選新第一題，組別、碼、成員不受影響。

送出後回應遺失或無法判定發布結果時，顯示「匯入結果待確認」，不宣告成功／零寫入，也不自動重送。
立即取得教師完整快照以恢復目前來源及選題；取得前停用再匯入與開題，不能繼續使用舊預覽開題。
尚無法同步則保持待確認；取得快照後才按現況恢復操作，不自行回滾其他分頁的較新更新。
若確認授權撤銷或活動過期，改依身分失效流程清登入並返回加入頁，不讓待確認畫面無限恢復舊操作。

已開始首回合時停用更換來源，既有預覽仍可查看。後端快照包含預覽，老師重新登入不需要重新選檔。本機來源結果區顯示不支援線上原稿回填，CSV 仍可下載；線上來源保留原有回填保護及結果待確認訊息。
