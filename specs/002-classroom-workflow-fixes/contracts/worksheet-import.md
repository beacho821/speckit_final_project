# XLSX 匯入契約

## 傳輸與工作表選擇

教師以 `POST /api/worksheet/import/xlsx` 上傳 File 本體，必須有教師 Basic 與目前 `X-Activity-Id`。支援 Content-Type 為 `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` 或 `application/octet-stream`；不接受 JSON Base64、multipart 或 HTTP Content-Encoding 壓縮。

`X-File-Name` 為 `encodeURIComponent(file.name)`。後端解碼失敗或含控制字元拒絕；移除路徑成分後，只接受非空且副檔名為 `.xlsx` 的名稱，不區分副檔名大小寫。檔名只當資料，不建立檔案。必須同時確認 Buffer 非空、實際大小與有效 XLSX 結構，副檔名與 MIME 都不能替代內容驗證。

上限為 **10,485,760 bytes，含上限**。此路由須註冊在全域 `express.json` 之前，依序檢查身分、活動、名單鎖定與媒體型別，再用 `express.raw({limit:10485760,inflate:false,...})` 讀取；不支援的 MIME 直接拒絕，不落入全域 JSON 解析器。其餘端點仍用原本 JSON 100 KB 上限。錯誤訊息使用「10 MiB」及允許大小，避免誤寫成十進位 MB。

可選 query `sheetId` 為檔案內實際工作表的正整數 ID，不能視為索引或 Google gid。未指定時：

- 單張工作表：顯示並選取該張，完整辨識後發布。
- 多張工作表：200 `{candidates:[{sheetId,title}]}`，保持檔內順序，不發布、不清選題。老師確認後重傳同一 File 並帶選定 ID。
- 無可用工作表：422 `EMPTY_WORKBOOK`。候選為可選工作表，不自動改用另一張以避開所選張的錯誤；隱藏／非常隱藏的表不列為可選學習單。

明確指定但不存在或不可選的 ID 回 422 `SHEET_NOT_FOUND`。不合併多張工作表，也不在所選張空白時偷偷選另一張。

## 成功預覽

本機與 Google 共用回應 `{source,mainQuestionCount,unitCount,fillCount,units}`。`units` 項目為 `{id,name,questionIds}`，依原稿順序排列。source 格式見 [資料模型](../data-model.md)，Google 保留原網址／gid 選取語意。候選與預覽為互斥回應。

## 辨識與拒絕條件

1. 先驗證 XLSX 可讀，拒絕損毀、加密、假冒副檔名、舊 XLS、巨集格式及空白內容。不得執行巨集、外部連結或公式。
2. 沿用 001 題號／作答表頭與穩定標記語法；辨識「題目」欄用於確認版面，但不把題目敘述當作題號。文字型別需支援一般文字、數字、富文字及超連結顯示文字。
3. 表頭、答案／備註標記及目標填空均轉為 `cell.master` 的主格位址後去重；合併從格不能覆蓋表頭欄選擇、產生重複標記或變成另一填空。
4. 混合題的直向合併主題號須連到各列子題，括號標記只建立子題身分，不當成學生答案。保留空白間隔語意，不將標題或空列當題目。
5. 同一完整題號出現兩個不同目標，或不同題號指向同一答案主格，皆回 422 並指出衝突與修正方式。無可辨識填空回 `NO_FILL_BLANKS`，已成功學習單不變。
6. 本機來源若缺必要題號／作答表頭且沒有 001 支援的完整識別標記，拒絕；不得因檔名符合範例就推測位置。一般表格路徑須能辨識題號及作答，題目敘述不另設必填內容。
7. 辨識必要欄位若是公式，回 422 `FORMULA_IDENTITY_UNSUPPORTED`，附工作表及主格位置，提示將表頭／題號／子題標記貼上為值。一般題目敘述、原答案或其他非識別格中的公式不計算；保留原答案型別供 Google 衝突比對，不因無關公式拒絕整檔。

## 發布及前端狀態

XLSX 路由通過身分／活動／未鎖定檢查後，必須在 `express.raw` 讀取主體前同步保留 `++importGeneration` 與 activityId；不能等較慢的上傳讀完才取序號。Google 路徑亦在任何遠端讀取前保留同一計數器的序號。序號只控制操作順序，候選、驗證未通過或發布前被拒絕不變更已發布學習單。

通過檔案及工作表驗證後才進入共用發布函式；同步重新檢查 `activityId`、兩來源共用的最新 importGeneration、首回合未開始及請求未失效。失敗回對應 409，不留下部分變更。成功一次更新來源及題目、移除 preparing 回合、通知角色快照，保留組別、加入碼、成員及其版本意義。

前端收到成功回應後清除舊選題；驗證未通過、發布前被拒絕、候選或取消選檔時，本次操作不得改動已發布預覽及選題，也不得回滾其他分頁已完成的更新。

已送出請求但回應遺失／無法判定結果時，顯示「匯入結果待確認」，不宣告成功或零寫入，不自動重送 POST。
立即不帶 after 讀取教師完整快照，以最新來源、預覽及準備回合為準；取得前停用再次匯入及開題，尚無法讀取則持續待確認。
若伺服器已換來源，畫面同步清除舊選題；若其他分頁已有較新來源，呈現該現況，不能用本次舊回應或舊快照覆蓋。
暫時連線失敗時維持待確認；若快照請求確認撤權或活動過期，清登入並返回加入流程，不繼續等待或重送舊匯入。

上傳中停用提交與來源切換，不提供可誤解為回滾的取消按鈕；選檔對話框取消不送出請求。多分頁舊回應與較慢 Google 匯入不能覆蓋較新的來源；任何解析期間若先開題，匯入必須被拒絕。

## 回填與匯出

本機來源回填固定回 `409 WRITEBACK_NOT_SUPPORTED`，先於 Google 權限檢查與任何回填服務呼叫。教師畫面同時說明不支援線上原稿回填。CSV 與搶答不受此限制。Google 來源沿用重新辨識目標、整批衝突檢查、只寫勝組答案及提交後讀回核對，不因共用辨識器而移除保護。
