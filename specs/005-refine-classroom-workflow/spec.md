# 功能規格｜調整教室操作流程

**功能目錄**　`specs/005-refine-classroom-workflow`\
**建立日期**　2026-11-20\
**狀態**　規格已驗證，可進入規劃\
**需求來源**　簡化教師導覽、教室投影及題目管理，並分開學生作答與歷史紀錄，統一題號與公布結果的呈現。

## 澄清紀錄

### 2026-11-20 澄清

- 問　開始新活動時如何處理上一場的出題清單？答　沿用完整清單及順序，所有題目均可在新活動重新出題。
- 問　刪除尚未開放的題目時，題目卡應保留嗎？答　同時刪除題目卡及清單項目。若日後要再使用，須重新匯入或手動新增。
- 問　重新匯入時如何處理既有題目？答　每次重新匯入視為新來源。成功後移除目前活動全部既有題目卡與清單項目，包含手動新增的題目；新來源的題目卡由老師重新選入清單。
- 問　手動題與學習單的題號可能相同時，如何安排與編號？答　首次匯入保留手動題。已選入的學習單題目可拖曳排序，未開放的手動題排在未開放的學習單題目後面。搶答題號依實際開放順序編定，學習單原題號不影響匯入或搶答編號。

## 使用情境與測試

### 使用情境一｜從題目卡安排課堂出題（P1）

老師匯入學習單後，能逐張查看題目卡、加入出題順序、直接編修題幹與標準答案，並依上課需要調整順序。臨時補充的題目也能加入同一份出題順序。

**優先理由**　備課時，老師需要在同一頁看清楚要出的題目與順序。

**獨立測試**　在空白教室先手動新增一道題目，再首次匯入含兩道單題及一組兩部分題目的學習單。用老師控制台及學生作答頁核對拖曳後的實際出題順序。

1. 匯入成功後，每道單題或完整題組各顯示成一張題目卡。老師可從卡片加入出題清單，卡片會顯示已加入的狀態。再次操作同一張已加入卡片時，清單仍僅有一筆。
2. 老師直接選取尚未開放的題目卡，即可編修並儲存題幹與標準答案，無須先準備回合。取消編修後，卡片仍顯示上次儲存的內容；若儲存失敗，顯示原因並保留輸入供重試。
3. 老師在新增題目的對話框填寫題幹與標準答案，介面不提供題號欄位。儲存成功後新卡片加入出題清單末端。題幹或標準答案只含空白時，對話框保持開啟，指出缺漏欄位，清單不增加；按取消也不增加。
4. 老師可在出題清單中拖曳已選入且尚未開放的學習單題目，例如把題組拖到另一張學習單題目卡前面。儲存後切到控制台或重新整理，下一個可開放的回合均為該題組，組內順序維持，手動題仍排在學習單題目後面。老師須明確按下「開放搶答」才會收件。
5. 開放後，老師嘗試修改該回合的題目或移動它的出題位置，介面說明目前的限制，已開放題目、收件及既定題號均維持。其餘尚未開放的學習單題目可繼續排序。
6. 上一場的清單含至少一題已定案及一題尚未開放時，開始新活動。新活動的清單保留所有卡片及原順序，每題均可重新開放。新活動重新自「第 1 題」開始編號，老師在控制台查閱上一場定案紀錄，重新整理或重啟後，仍看到按當時實際開放順序編定的題號及題組部分序號。
7. 老師刪除本活動尚未開放的題目後，題目卡及清單項目皆消失，控制台按其餘題目的相對順序出題。若同一題已在上一場定案，上一場的紀錄仍可查閱。若老師取消刪除，題目卡、清單位置及題目內容均維持。
8. 在首題開放前重新匯入，確認畫面提示既有題目卡（包含手動新增題目）與出題清單將清除。匯入成功後只顯示新來源的題目卡，出題清單為空。取消、檔案無效或匯入失敗時，原題目卡與清單完整保留。即使重選同一份檔案，也依新來源處理。
9. 老師先新增手動題，再首次匯入含原題號「第 1 題」的學習單。匯入成功且手動題保留。將兩張學習單題目卡加入出題清單並對調順序後，依序開放三個回合。學生依序看到拖曳後的第一張學習單題目為第 1 題、第二張為第 2 題，手動題為第 3 題。

### 使用情境二｜用同一列導覽切換工作並開啟教室投影（P1）

老師在指定教室中用同一列導覽切換工作區，在任一工作區開啟全班投影。

**優先理由**　主持時，老師要能直接到達分組、題目與控制台，也要能從當前工作區快速開啟投影。

**獨立測試**　登入教師身分，選取一間有兩組的教室，在三個工作區逐一檢查導覽及投影連結，再由其中一組送答。

1. 三個工作區的導覽都依序顯示「分組管理」、「題目管理」、「老師控制台」，並標示目前頁面。原「教室管理」工作區以「題目管理」命名，活動準備側欄及其中重複的導覽入口移除。「開始新活動」可從老師控制台進入確認流程。
2. 從導覽右側的「開啟教室投影」連結開啟所選教室的投影，原頁可繼續主持。投影呈現全班的教室名稱、已開放題目、階段及各組收件狀態。某組送答時，只更新該組在本教室投影中的收件狀態。
3. 分組管理仍可提供學生加入碼，畫面沒有組別投影入口或產碼操作。投影不要求輸入任何投影碼。舊組別投影網址或碼無法載入組別資料，也不會因而取得全班投影權限。
4. 兩間教室各自開放回合時，每個投影只更新所選教室的狀態。未登入教師直接開啟投影時，畫面提示先登入教師端，且不顯示教室資料。

### 使用情境三｜在作答與歷史紀錄間切換（P1）

學生用導覽切換「作答」與「歷史紀錄」，能讀懂目前的題號，也能逐題對照本組先前的答案及公布結果。

**優先理由**　學生可專注作答，也可以回看答案而不失去當前輸入。

**獨立測試**　以 360 像素寬的學生畫面加入一間教室，完成一道單題及一組兩部分題目，驗收答對、答錯與未作答的歷史紀錄。

1. 加入後預設進入「作答」。導覽標示當前頁，點「歷史紀錄」只顯示已公布紀錄或空狀態，點「作答」回到最新回合狀態。於同一回合輸入後切到歷史再返回，尚未送出的輸入仍在。老師於學生查看歷史時開啟下一回合，學生留在歷史頁，回到作答時顯示新題目，舊草稿不會帶入。
2. 作答及歷史均顯示完整題號。第一題為單題時只顯示「第 1 題」；第一題為兩部分題組時，分別顯示「第 1 題，第 1 部分」及「第 1 題，第 2 部分」。已公布紀錄使用該回合開放時的題號。
3. 歷史的每題標題顯示完整題號與題幹，不出現「已公布回合」或送出狀態字樣。標題下顯示「已回答：〈本組答案〉」，空一行後，答對顯示「正確」，答錯或未作答顯示「正確答案：〈公布的答案〉」。未作答顯示「已回答：未作答」。
4. 尚待審核時，歷史頁沒有該回合的題目、答案或判定。定案公布後，學生可看到該題的本組答案與結果；其他組別的逐題答案不會出現在學生歷史頁。

### 邊界情況

- 無題目或出題清單為空時，題目管理頁提示可匯入或新增題目；控制台提示先至題目管理加入題目，且無法開放空回合。
- 匯入中或儲存結果待確認時，顯示狀態並暫停相依的開題操作。連線中斷或另一個教師頁已儲存新版本時，介面提示老師核對最新資料，避免靜默覆寫。無效操作不變更上一次有效的題目內容及排序。
- 本活動首題開放後不得重新匯入。嘗試時須提示已有回合開始，保留目前題目、清單及回合資料。重新匯入成功也須保留其他活動已保存的回合。
- 匯入資料缺少題幹或標準答案時，卡片指出缺漏並可直接補填；該題須補齊並儲存後才能開放。
- 可排序範圍為清單中尚未開放的學習單題目。拖曳至範圍外或取消拖曳時，保留原順序。題組的排序及刪除均以整組為單位。本活動已開放的題目不可刪除，操作遭拒時提示限制並保留原資料。刪除仍被舊版未開放準備回合引用的題目時，一併移除該準備回合。重啟後教室可正常恢復，老師可開放清單中的下一題。
- 只用鍵盤即可開啟新增對話框、修正缺漏、取消或儲存，也可用鍵盤將尚未開放的學習單題目移至與拖曳相同的位置，並切換教師與學生導覽。操作中可看見焦點，關閉新增對話框後焦點返回「新增題目」。
- 回合已收件時，切換學生導覽後再返回作答頁，顯示伺服器接受的答案並維持鎖定。活動失效時依既有加入流程重新驗證，清除該活動的作答草稿。
- 歷史題幹、答案與判定取自該回合定案時可公布的記錄。較舊的紀錄缺少可確認的正解時，顯示「正確答案：未提供」，不以未公布的資料或其他組別的提交文字推測正解。

## 需求

### 功能需求

| 編號 | 驗收要求 |
| --- | --- |
| FR-001 | 指定教室的教師工作區共用導覽，依序呈現「分組管理」、「題目管理」、「老師控制台」並指出目前頁面。「題目管理」取代「教室管理」名稱，移除活動準備側欄及其重複導覽；老師控制台提供「開始新活動」及原有確認與停用條件，確認時說明會沿用完整出題清單及順序。 |
| FR-002 | 三個教師工作區在導覽右側提供「開啟教室投影」超連結（`a` 元素）。選取後在獨立檢視開啟目前教室的唯讀全班投影，教師原工作區保留。投影沿用教師登入權限，一間教室只有一個全班投影入口。 |
| FR-003 | 移除組別投影及其入口、產碼與輸碼流程；舊組別投影碼無法取得任何投影資料。學生加入碼仍用於學生登入。投影按教室隔離，僅顯示教室名稱、階段、已開放題目、各組收件狀態及已公布摘要；畫面不揭露未公布答案、個人資料、學生加入碼或教師控制項。 |
| FR-004 | 題目管理支援既有 Google 試算表與 XLSX 匯入。匯入後每道單題或每組題組有一張獨立題目卡，含題幹及題組各部分。老師可由卡片加入目前活動的出題清單，同一題目只可加入一次。首次匯入保留手動新增的題目及其相對順序。學習單原題號只用於辨識來源，即使與目前顯示的搶答題號相同，仍可正常匯入。重新匯入限本活動首題開放前，並須經老師確認。每次重新匯入都視為新來源，成功後以新來源的卡片取代舊卡片，包含移除原手動新增的題目，並清空本活動的出題清單。取消或失敗時保留上一次有效的資料。 |
| FR-005 | 已加入清單且尚未開放的學習單題目可在清單內拖曳排序，也可用鍵盤完成同樣的排序。這些學習單題目排在尚未開放的手動新增題目前面，手動題依新增順序排列。成功儲存的順序在切頁與重新整理後仍可查閱，控制台依此提出下一個尚未開放的題目供老師明確開放。已開放的題目與歷史定案結果不受後續排序影響。開始新活動時沿用上一場的完整清單及順序，所有題目恢復為未開放，新活動從第 1 題開始。上一場的收件與定案結果保留在原活動，教師歷史顯示各回合開放時的正式題號與題組部分序號。老師可經確認刪除本活動尚未開放的題目，同時移除題目卡與清單項目。刪除後保留其餘題目的相對順序；重新使用被刪除的題目須重新匯入或手動新增。刪除不影響其他活動已保存的回合。 |
| FR-006 | 老師可直接從未開放的題目卡編修題幹與標準答案，並儲存或取消。獨立的「備課題目」欄位移除。題目正在儲存、結果待確認或有尚未儲存的修改時，控制台提示先完成相關操作才可開放該題。 |
| FR-007 | 「新增題目」開啟模態對話框，可填寫題幹與標準答案、儲存或取消。題號自動給定，對話框沒有題號輸入。必填內容有效才可儲存，成功後新題加入清單末端，取消或失敗不新增題目。鍵盤可完成操作，關閉後焦點返回新增入口。 |
| FR-008 | 學生加入後預設顯示作答頁，可透過共用導覽在「作答」和「歷史紀錄」間切換。作答頁沿用等待、作答及收件鎖定狀態。導覽切換保留同一回合的草稿與伺服器收件結果；舊回合草稿不帶入新回合。 |
| FR-009 | 學生作答及歷史使用「第 N 題」標示單題，使用「第 N 題，第 M 部分」標示題組各部分。N 依該活動實際開放搶答的順序自 1 起連續編定，M 為題組內自 1 起算的部分順序。學習單原題號與新增時間均不決定搶答題號。每次開放時固定該回合的題號，後續拖曳僅改變未開放題目的先後。 |
| FR-010 | 學生歷史只顯示本活動已公布的逐題紀錄。題幹與完整題號用作標題，移除「已公布回合」及送出狀態文字。標題下顯示「已回答：…」，空一行後依定案結果顯示「正確」或「正確答案：…」。無公布紀錄時提供明確空狀態。 |
| FR-011 | 作答或歷史的資料須符合學生目前活動及所屬組別的權限。錯誤或資料待確認時以正體中文顯示原因與可採取的操作。教師與學生導覽和主要操作支援鍵盤並有可辨識的焦點與目前頁面標示。 |

### 主要資料

- **教室投影**　隸屬一間教室的唯讀全班檢視，呈現目前回合向班級公開的資訊。
- **題目卡**　代表一道單題或完整題組，包含題幹、各部分及供教師使用的標準答案。題目可源自匯入或手動新增；重新匯入成功後，只有本次匯入的題目卡留在目前活動。
- **活動出題清單**　目前活動已選入且可由老師安排順序的題目。新活動沿用上一場的完整清單與順序，各活動分別記錄開放狀態與已開放回合的題號。
- **學生歷史紀錄**　以該活動的已公布回合為來源，逐題呈現當時題幹、題號、本組答案及可公布的結果。

## 成功標準

### 可量測成果

- **SC-001**　在至少 3 位教師試用者中，每位都能依畫面提示於 90 秒內將兩張已匯入的卡片加入清單、拖曳改變先後、直接編修其中一題並從控制台辨識下一題。另各驗收一次重新匯入成功與失敗，核對成功後舊卡片與清單項目均為零，失敗時既有卡片與清單完整保留。
- **SC-002**　從三個教師工作區各開啟投影一次，每次均只需選一次導覽連結且無須輸碼。兩間教室各進行三次收件狀態更新，每次在 2 秒內反映於所屬教室投影，另一間教室的收件狀態維持原值。
- **SC-003**　至少 3 位學生試用者均能在 360 像素寬的畫面各用一次導覽操作來回切換，在沒有水平捲動的情況下找回原草稿，並正確指出歷史中的本組答案與公布結果。
- **SC-004**　各驗收一次單題及兩部分題組。作答與歷史的每筆題號及每個部分均與回合開放時一致。「正確」、「正確答案：…」及未作答案例各驗一次，公布前答案揭露與跨教室或跨組逐題答案洩漏均為零。

## 假設

- 「加入」指將學習單題目加入目前活動的出題清單。手動新增題目預設加入清單末端。題組整張加入與搬移，組內小題維持學習單原有順序。若介面預覽尚未開放的搶答題號，應依目前出題清單順序顯示。
- 投影沿用教師登入；校內投影設備可顯示老師開啟的全班檢視。學生的加入及驗證流程沿用既有規則。
- 「正確」以老師最終公布的判定為準。答錯或未作答時，已公布的教師補答優先，其次使用定案時該題可公布的標準答案。
- 歷史紀錄沿用目前活動範圍。既有紀錄優先採用已保存的搶答題號與題組資料。缺少搶答題號時，依該活動既有的開放回合順序及題內順序顯示。後續排序不會重編舊題。
- 本次調整沿用既有教室存檔、老師開放與結束搶答、審核定案、活動切換及學習單回填流程。題目編修與排序使用既有課堂階段及資料權限判斷可操作範圍。
