# 資料模型｜調整教室操作流程

## 教室與活動

| 欄位或關係 | 用途及驗證 |
| --- | --- |
| `Classroom.id` | 唯一教室識別，沿用活動定位、分組及投影的範圍驗證。 |
| `Activity.id`、`activityEpoch` | 分別識別一場活動與目前程序的授權世代。舊活動的學生授權與寫入請求依現行規則失效。 |
| `Activity.worksheet` | 已成功選定的學習單及來源資料。保留來源單位、填空及原值，供回填核對。 |
| `Activity.units` | 目前活動的題目卡，包含已匯入及手動新增題目。每張卡的 `unitId` 在本活動內唯一，子題用既有 `questionKey` 編修。 |
| `Activity.queueUnitIds` | 目前活動已加入的題卡順序。每個 ID 須存在於題庫且只出現一次。已選學習單題目在前，手動題依新增次序排在後方。所有手動題於建立時一併加入。 |
| `Activity.catalogRevision` | 執行期的題目管理版本。增刪、加入、排序、編修、發布匯入及實際開題成功時推進。重啟或新活動依當次活動範圍重新取得，不與其他教室版本比較。 |
| `Activity.rounds` | 各回合依建立、開放的既有順序保存。有效開放序列只含 `active`、`reviewing` 與 `ended`。 |

待開放順序是清單略過已開放題目後的結果。教師畫面已開放區依回合快照排序。新選入的學習單題插入已選學習單段落末端，仍在手動題之前；若有已開放的手動題，其實際序號不變。開始新活動時複製完整清單、題庫與來源，回合從空集合開始，舊活動的定案快照繼續供教師查閱。

## 題目卡、來源與寫入

- 從已解析的學習單建立題目卡，一個單題或一個題組對應一張卡。維持題組內部分順序。來源題號保存在既有 `questionId`，填空鍵保存在 `fillBlankId`。來源解析仍檢查同一份學習單內的無效或重複識別。
- 手動新增使用伺服器產生的題卡與子題鍵，以及非顯示用的手動 `questionId`。題幹及至少一個去除空白後有效的標準答案必填。新增卡片與排入清單一起儲存。工作表題號與手動內部鍵、實際搶答題號各有用途。
- 編修時驗證活動、題卡未開放、`questionRevision` 及題目管理版本。新增及編修沿用現有收件中與待審核的限制。未開放學習單題仍可排序。學生在題目未開放前無法讀取題幹與標準答案。已開放回合的快照與現有審核補答各自保存。
- 排序輸入只包含恰好一份目前待開放、已加入的學習單 ID 排列。保留已開放卡片在設定中的位置及手動題的新增順序。刪除限本活動未開放卡片。題卡、清單項目及仍引用該卡的舊版未開放準備回合在同一次教室交易移除。存檔失敗時三者均保留。仍需回填的來源定位資料保留在 `Worksheet`，已刪題不應出現在即時預覽或待開放清單。
- 開題檢查下一題 ID、版本、分組、題幹、標準答案與回合階段。題目管理版本與快照在同一現有教室交易寫入。未成功寫檔則維持上次有效狀態；客戶端在結果不明時先重新讀取再操作。
- Google 與 XLSX 格式整合共用同一提交。已有學習單時需版本相符的取代確認。首次成功匯入保留手動題；重新匯入成功時清除該活動既有卡片、清單與未開放準備回合，再發布新來源的題卡。工作表候選未選定、資料無效、來源已更新或寫檔失敗時維持原資料。

## 開放快照與公布結果

| 欄位或資料 | 用途 |
| --- | --- |
| `Round.sequenceNumber` | 實際開放時以該活動開過的回合數加一，正整數且同活動連續唯一。準備回合尚無正式號碼。 |
| `Round.isMultipart` | 開放時從題組結構及顯式小題資料判斷。只有一個部分的顯式題組仍顯示「第 1 部分」。 |
| `Round.questions` | 開放時的子題快照與來源位置，既有陣列順序決定部分序號。送答仍依既有回合內 `questionId` 驗證。 |
| 公布結果 | 從已定案的回合快照、提交、最終判定與補答導出。教師保留原有全班查閱。現有與封存活動的回合摘要提供正式題號，逐題明細同時提供部分序號。兩者從回合快照或舊資料回合順序推得。學生表示本組已答或未答、最終判定及需要顯示的一個公布正解。 |
| 投影快照 | 從教室目前活動導出，不另存檔。只使用教室名稱、階段、可見題目、組名、收件標記及定案摘要。 |

## 舊存檔載入

1. 保留 schema 1。新欄位缺失代表舊格式；已存在但格式錯誤或有無效引用時，沿用單間教室隔離及錯誤回報。明確儲存的空清單不重新推導。
2. 舊清單補入已開放或已準備的學習單題卡，依既有回合順序排列，接上原手動卡的建立順序。其他舊學習單題仍可從題庫選入。舊準備回合可在教師明確開題時沿用或依清單換成正確的下一題；它未收答案且不佔正式題號。
3. 舊回合缺少題號時，依同活動儲存的開放回合順序推得。缺少題組旗標時，依回合題目數及可辨識的來源小題資料推得。重啟轉為待審核的回合仍占用原題號，既有收件及定案資料保持可讀。
4. 保存回合時保留新增的正式題號和題組旗標，既有用於公平等待的暫態時鐘不納入持久編號。發碼與憑證保存維持憲章的既有規則。
