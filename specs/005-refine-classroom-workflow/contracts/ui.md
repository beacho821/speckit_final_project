# 介面契約｜教室工作區

## 教師導覽與投影（FR-001 至 FR-003）

- 教室工作區維持返回教室清單與教室名稱。由左至右為「分組管理」、「題目管理」、「老師控制台」，用 `aria-current` 標示目前頁面。題目管理沿用教室內原設定路徑。
- 三頁導覽右側為真正的超連結「開啟教室投影」，指向 `/teacher/classrooms/:classroomId/projection`。一般點擊或鍵盤啟用時保留教師原頁，由同源已驗證教師頁開啟或聚焦該教室的投影。連結可辨識會開啟獨立分頁。單獨開啟而沒有授權來源時顯示如何從教師端開啟。
- 投影驗證來源視窗、同源及教室識別，只顯示唯讀快照。登出、教室刪除或心跳停止時清空內容。開始新活動時回到同教室的當前活動。已移除的 `/projection` 路徑顯示從教師導覽開啟投影的指引；分組頁保留學生加入碼。
- 老師控制台顯示「開始新活動」，確認框說明複用完整清單與順序。既有收件、審核及回填期間限制保留。原活動準備側欄及其中重複入口移除。

## 題目管理與下一題（FR-004 至 FR-007、FR-009）

- 匯入 Google 試算表或 XLSX，顯示可選題目卡和活動出題清單。一張卡代表一題或整組，顯示題幹、各部分、已加入或已開放狀態及可執行動作。選取可編修的題目卡即可填寫題幹及標準答案。
- 清單顯示實際已開放回合及待開放順序。待開放學習單卡可拖曳到有效落點，也能用上移、下移按鈕以滑鼠、觸控或鍵盤操作。卡片換位後保留對應焦點並回報位置。移出有效落點或取消時維持原順序。手動題依新增順序排在待開放學習單題之後。
- 新增題目對話框包含題幹、標準答案、儲存和取消。題號由實際開放決定。錯誤保留輸入並指向需修正欄位，關閉後焦點回到新增入口。刪除確認指明會移除題目卡與清單項目。重新匯入確認說明會移除目前全部卡片及清空清單，包含手動題。
- 控制台依伺服器清單顯示下一題。未完成編修、等待匯入確認或缺少開題所需資料時，提示原因與修正入口。「開放搶答」送出一次明確操作。版本改動時顯示提示並更新，教師需確認最新題目後再開放。已開放題目及部分題號以快照顯示。教師控制台的歷史回合標題顯示正式題號，展開後各題顯示完整題號及部分序號。換場或重啟後沿用原活動的編號。

## 學生導覽與歷史（FR-008 至 FR-011）

- `/student` 為作答，`/student/history` 為歷史。加入後預設作答。點選導覽及瀏覽器上一頁、下一頁可切換並更新目前頁面標記。網址只表示所選頁面。
- 同一活動的作答同步與同回合草稿跨頁保留，收到新回合時更新資料並清除舊草稿。學生停留在歷史頁時維持該頁。已收件時回到作答顯示該組伺服器接受的唯讀答案。
- 歷史顯示載入中、無公布紀錄、失敗重試或逐題結果。作答與歷史均使用「第 N 題」或「第 N 題，第 M 部分」。歷史標題包含題號及題幹，其下顯示「已回答：…」並保留一空行，再顯示「正確」或「正確答案：…」。無作答或無可用公布正解分別顯示「未作答」、「未提供」。
- 360 像素寬度時導覽及各題可單欄使用，操作與目前焦點清楚可辨識。過期時沿用學生驗證及草稿清理行為。
