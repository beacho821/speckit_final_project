# 資料模型：教師定案與學生倒數提示

## 回合審核

- **範圍**　目前教室、活動識別及世代、回合識別。回合結束收件後，依現有流程從進行中進入待審核，定案後進入已結束。
- **資料**　`reviewRevision`、按顯示順序排列的題目、目前有效判分、參與資格、老師補答和 `missingSupplementQuestionIds`。以既有完整題目識別連結子題，以 `questionLabel` 顯示課堂題號。
- **驗證**　只允許教師審核目前回合。儲存時須帶最新審核版本及合法的題目、組別和修改內容。每個子題由具資格組別的正確作答或有效補答滿足。純空白視為無補答，其餘答案保留原文。

## 教師審核草稿與衝突

| 資料 | 識別 | 基準與目前值 |
| --- | --- | --- |
| 判分 | 組別識別及題目識別 | 有效正誤，保留 `false` 為合法值 |
| 補答 | 題目識別 | 原文或空值，空白與未填等效 |
| 資格 | 組別識別 | 有資格或已取消資格，省略取消資格欄等效於有資格 |

草稿只在同一教師分頁與回合存在。每筆本機修改對照開始編輯該筆時的基準值，並與最新已存值比對。

| 比對結果 | 草稿處理 |
| --- | --- |
| 最新已存值等於基準，本機有修改 | 保留本機修改，可送出 |
| 本機值等於基準，只有已存值更新 | 使用最新已存值 |
| 最新已存值與草稿值相同 | 該筆已對齊，無須送出 |
| 最新已存值與草稿值不同，兩者皆異於基準 | 並列兩值，等待老師逐筆選擇 |

選擇需綁定核對過的最新已存值。該值再次變更時重新判斷該筆衝突。選擇保留最新值可移除該筆修改，選擇草稿則將該筆保留為待儲存修改。所有衝突處理後，將差異套到最新版本，按現有規則重算待補答與可儲存項目。重新判分或資格變動而失效的補答草稿可供複製，並排除於儲存內容。沒有有效差異時可結束核對，無須送出空白更新。

## 審核操作與定案結果

- **操作識別**　活動範圍、回合識別、操作種類（儲存或定案）及提交時使用的審核版本。儲存還需暫存提交的欄值，用於斷線後核對。
- **狀態**　審核中 → 處理中 → 已確認或遭拒。結果無法判定時先進入待確認，收到符合範圍與本次更新序號的新快照後才處理。仍未確認時可再重新取得狀態。已確認未定案且仍在審核的回合，可由教師手動重試。
- **結果**　保留同回合的 `winnerGroupId` 及顯示名稱，`null` 表示無勝組。操作回饋區可跨越審核畫面卸載，直到切換回合、活動或離開控制台。定案權威結果沿用已封存回合。

## 學生作答草稿與倒數

- **鍵值**　當前學生組別、活動範圍及回合。欄值沿用完整題目識別。
- **倒數**　正數剩餘毫秒從收件快照或等待拒收回應取得，依本機經過時間倒數。歸零後需同時符合仍在收件、尚未收件成功且沒有未確認的送出，才可手動提交。
- **保留**　同一回合的倒數與校正保留欄值。換回合後按既有流程清除草稿與倒數。
