# 資料模型：自動補答與逐筆改判

| 實體或欄位 | 約束與生命週期 |
| --- | --- |
| 回合範圍 | 「同一教室、活動及世代的目前待審核回合」。封存後判分、勝組及補答不可修改。 |
| 回合題目 | 「每項以完整題目識別，標準答案用開題時的順序」。自動候選採「第一個非空白答案，保存原文」。 |
| 已存人工補答 | 「每題至多一筆有效值，純空白視為缺少」。只作為舊回合待審核時的優先候選。暫時不需補答時保留原值，待定案時才產生實際補答列。 |
| 補答候選 | 「同一子題最多一筆，來源為 legacy 或 configured」。候選含題目識別、原文、來源，且僅出現在教師審核資料。無可用來源則省略該候選。 |
| 作答判分 | 「只可改判已收件的組別與子題，判定為布林值」。有效值優先採教師改判。作答原文、自動判分及收件順位保留。 |
| 資格 | 「每個已收件組別的取消資格狀態為布林值」。已取消資格的組別不消除補答。 |
| 審核版本 | 「修改或定案必須符合目前的整數審核版本」。同一修改不得重複提交，同一欄無差異不產生寫入。 |
| 定案補答 | 「每個仍需補答且有來源的子題最多一筆」。封存形態為既有 `questionId` 與 `text`。缺來源時無補答列，已定案歷史不重算。 |

## 關係及轉移

回合在收件中凍結標準答案與收件原文。停止收件進入待審核並完成自動判分。待審核時計算候選，排除有具資格組別答對的子題。教師草稿可重算畫面，儲存成功後才影響權威判定。定案時用權威判分再次篩選補答並以既有規則選勝組。已定案結果供教師歷史、學生公布、CSV 與勝組回填使用。
