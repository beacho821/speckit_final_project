# 介面契約｜改善教室操作與活動結算

## 教師導覽與投影（FR-001 至 FR-003）

登入後從教室列表開啟或新建教室，進入 `/teacher/classrooms/:id/groups`。題目管理、老師控制台及投影沿用現有網址。工作區導覽標示目前頁。三個工作區都能用「開啟教室投影」開啟獨立分頁。若瀏覽器阻擋，原頁提示允許開啟後重試。

| 投影狀態 | 顯示與轉移 |
| --- | --- |
| 等待 | 已從教師頁開啟或重新整理，等待驗證及第一份快照。顯示「正在連線」，成功後顯示公開內容。 |
| 正常 | 顯示所選教室的公開快照。健康輪詢回覆無更新時維持。 |
| 重連 | 以首次偵測到中斷的時間起算。截止前保留最後一次正常畫面並標示「重新連線中」，10 秒後只保留提示。沒有已取得的快照時只顯示提示。重試、心跳或投影重新掛載不延長截止時間。成功取得完整快照後恢復正常。 |
| 需重開 | 明確失去原教師頁、無登記的投影來源或教室已不存在時，提供從教室導覽重新開啟的指引。未經授權的直接開啟可提示先登入教師端，不顯示教室資料。 |
| 未授權 | 收到登出通知或確認認證失效時立即清除內容及重試，提供教師端登入指引。 |

原頁與投影採同源視窗訊息。原頁僅向為該教室登記的視窗轉送狀態及公開快照。投影就緒訊息也須由登記視窗發出。回覆須來自目前的原教師頁且教室相符。收到超過重連截止的訊息不得重新顯示舊內容。恢復連線通知會立即安排完整讀取；沒有瀏覽器通知且原請求無回應時，先等待請求逾時偵測中斷。頁面恢復可見或收到有效訊息時重新核對截止時間。漏掉數次心跳不能判定為未授權。跨活動或已停止的請求回應不得復原舊畫面。 [投影 HTTP 契約](http.md)

## 題卡操作（FR-004 至 FR-006）

1. 可編修卡片用鉛筆按鈕進入編修，具「編修題目」的可辨識名稱。單題和題組均提供一個「儲存修改」。確認保存後採用回應的題卡，回到檢視並將焦點移回編修圖示；同步時不得閃回舊版資料。
2. 送出期間避免同卡重複提交。拒絕或結果待確認時保留草稿，顯示修正、核對最新資料或重試的提示。資料過期後保留版本基準，教師明確核對才可採用最新版。若卡片已移除、開題或因回合狀態暫不能編修，仍可查閱本次輸入，並阻擋無效提交。若儲存回應未送達，核對送出後取得的新完整資料。範圍、題卡和各部分識別一致且內容完全相符時，比照成功儲存結束編修。否則保留草稿並提示核對，不自動重送。
3. 可刪除卡片用紅色垃圾桶按鈕，具「刪除題目」的可辨識名稱。保留原確認流程及取消後焦點。成功移除時焦點落在下一個合理操作位置。
4. 有可移位置的題卡在頂端提供長條把手。滑鼠及觸控拖曳時，代表題卡的預覽及插入線共用同一有效落點。把手之外保留正常捲動。取消、失去指標、放開在無效範圍或版本變更時移除預覽。只在有效落點且排序成功後顯示新順序。
5. 上下箭頭圖示支持單點及鍵盤，具「上移」、「下移」的可辨識名稱、可見焦點與邊界停用狀態，沿用原生按鈕及排序結果通知。畫面省略常駐的拖曳及上下移文字按鈕。當卡片位置變更時保留合理的焦點位置。

## 老師控制台結算（FR-008、FR-009）

- 一般主持畫面只顯示「結算」入口。收件或待審核時停用並說明待完成的步驟。活動狀態未確認時先等待同步。
- 由教師選取後，結算區才呈現「回填與匯出」及「開始新活動」。已定案且來源支援時可回填，有定案紀錄時可匯出。不適用的操作顯示清楚原因。空活動可進入結算並確認開始新活動。
- 選取返回主持時回到同一活動，保留主持資料並收起結算操作。回填或切換活動正在處理時，開始新活動入口應停用，回填佔用顯示原因。切換操作保留取消、確認及成功後新場主持畫面的流程。
- 其他教師頁面開始收件或審核時，結算收起、關閉相關確認並提示先完成該回合。若活動範圍已過期，停止舊範圍的介面操作，提示重新取得目前教室活動。切換回應失聯時先核對目前活動，再決定正常顯示或允許重試。認證遭拒時依既有登入流程處理。

## 學生歷史紀錄（FR-007）

| 公布資料 | 逐題呈現 |
| --- | --- |
| 有本組答案，`correct === true` | 本組答案與綠色「正確」。 |
| 有本組答案，`correct === false` | 本組答案、紅色「錯誤」與「正確答案」，沿用缺值提示。 |
| 沒有本組答案 | 「已回答：未作答」與可公布正解，使用中性色。 |
| 有本組答案，`correct === null` | 本組答案與已公布內容，使用中性色。 |

公布前維持原有等待及歷史顯示。依文字即可辨識判定，360 像素寬的學生畫面仍可讀取題組各部分和正解。
