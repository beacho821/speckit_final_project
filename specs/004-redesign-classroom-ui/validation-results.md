## 瀏覽器與同步

以 Chromium 在同一台開發機透過區網網卡位址連線。教師、兩個學生組別及組別投影使用獨立瀏覽器環境，全班投影由教師視窗開啟。依 [驗收指南](quickstart.md) 的起訖，量測從送出操作至最後一個應更新畫面的時間。

| 操作 | 第 1 次 | 第 2 次 | 第 3 次 |
| --- | ---: | ---: | ---: |
| 開放搶答 | 267 毫秒 | 211 毫秒 | 210 毫秒 |
| 學生送答 | 230 毫秒 | 212 毫秒 | 213 毫秒 |
| 結束搶答 | 205 毫秒 | 200 毫秒 | 96 毫秒 |
| 確認定案 | 92 毫秒 | 211 毫秒 | 109 毫秒 |

所有樣本均低於 2 秒。走查 1440 px 桌面、768 px 窄版、360 px 手機及 1280 × 720 投影。以 720 CSS px 檢查 1440 px 桌面在 200% 縮放下的等效版面重排。長題幹在手機及投影可換行。鍵盤完成登入，刪除對話框開啟時聚焦「取消」，按 Esc 後回到教室列。亦確認未儲存草稿切到控制台仍阻止開題，學生重新整理仍顯示已收答案，老師登出後全班投影清除。Impeccable 版面掃描無發現。
