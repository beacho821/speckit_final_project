# 規格品質檢查表｜教室介面重新設計

**日期**　2026-11-18\
**功能**　[教室介面重新設計](../spec.md)

## 內容品質

- [x] 規格聚焦使用行為及結果。JSON 存放方式是指定交付條件，框架、介接細節與程式結構由後續規劃決定。
- [x] 各情境說明師生可完成的工作。
- [x] 內容使用教室活動用語，供非技術讀者閱讀。
- [x] 情境、需求、資料、成功標準與假設均已填寫。

## 需求完整性

- [x] 需要採用預設的行為均已記錄，沒有待澄清項目。
- [x] FR-001 至 FR-012 的入口、動作和結果可驗證。
- [x] SC-001 至 SC-004 均有可量測的判定條件。
- [x] 成功標準可透過頁面、操作與時間量測驗證。
- [x] 每個主要使用情境都有驗收步驟。
- [x] 包含錯誤輸入、重複送答、過期授權、未完成審核、重啟及存檔失敗的邊界情況。
- [x] 教室存檔範圍、教師授權及投影可見資料均有界定。
- [x] 已記錄既有登入、加題、成果與搶答規則的依賴，以及投影與恢復主持的假設。

## 功能就緒

- [x] 每項需求都能以驗收步驟或明列的畫面、檔案及授權結果判定。
- [x] 已涵蓋五個教師頁與三個學生狀態。
- [x] 可依成功標準執行後續介面與功能驗收。
- [x] 需求保留使用者指定的 JSON 條件，其餘設計細節可在規劃階段決定。

## 現況核對

| 項目 | 現有功能 | 新規格涵蓋 |
| --- | --- | --- |
| 初始登入 | 教師密碼、學生加入碼與名稱 | 沿用現行介面 |
| 教室列表與存檔 | 伺服器啟動時建立一個記憶體活動 | 建立、恢復主持、刪除，多教室 JSON 自動儲存與載入 |
| 教室管理 | 教師工作台可匯入、預覽、手動出題與設定準備回合 | 獨立教室管理頁與導覽 |
| 分組管理 | 同一工作台已有名單管理及學生加入碼 | 獨立分組頁、兩個導航入口、各組投影碼 |
| 老師控制台 | 已有開始搶答、停止收件、改判、教師補答、公布及歷史回合 | 獨立控制台、取消及恢復資格、已定案答案清單 |
| 投影 | 現有專案未提供投影入口或投影授權 | 教室與指定組別大螢幕投影 |
| 學生等待 | 備題時已有等待提示，工作台上方顯示組別 | 明確等待畫面與指定文案 |
| 學生作答 | 已有逐題題幹、輸入欄與整組送出 | 以題組作答頁呈現 |
| 學生已送出 | 已有收件確認、唯讀答案與同組同步 | 明確鎖定狀態與指定文案 |

現況依據為教師與學生工作台、回合與審核元件，以及伺服器活動建立流程。執行 `npm test` 驗證既有功能，43 個測試檔、139 個案例全部通過。新介面與存檔流程的驗收條件列於規格。
