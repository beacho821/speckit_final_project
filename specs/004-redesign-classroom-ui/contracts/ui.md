# UI 版面與互動契約

## 版面方向

沿用現有紫色主要操作與中性底色。登入後以教室名稱、回合階段及單一主要操作構成首屏。使用標題、對齊、留白及細分隔線組織區塊。名單與歷史採垂直清單，操作按鈕保留在相關資料旁。初始登入沿用既有版型、文字和操作。

- 教師工作區最大寬以 1200 px 為初始值，學生作答區以 640 px 為上限。距離採 4 px 基準，標籤相鄰 4–8 px、欄位群組 12–16 px、獨立段落 24–32 px。
- 登入後一般正文以 16 px 為基準。主操作延續 `#5B55D8` 搭白字，背景 `#F7F8FA`，次要文字用 `#525D73`。錯誤、資格與階段均有文字。鍵盤焦點清楚，主要觸控目標至少 44 px。
- 寬度達 960 px 可配置工作主欄與側欄。教室清單約採三分之一建立、三分之二歷史。管理與控制台約採三分之二主內容、三分之一側欄。窄版依文件順序堆疊，導覽可換行，操作鍵仍和對應段落相鄰。獨立投影使用深底 `#11162B`、淺字 `#EEF0FF`。1280 × 720 時題幹以約 36–52 px 為起點，階段與組名約 24–32 px。

## 教師頁面

| 頁面與路徑 | 畫面順序與主要互動 |
| --- | --- |
| 教室列表 `/teacher/classrooms` | 頁首為「我的教室」及登出。內文左側建立教室，只有名稱及「建立教室」。右側依更新時間排列歷史清單，每列含名稱、階段、更新時間、「恢復主持」及次要的「刪除教室」。無教室時引導使用建立表單。啟動轉換存檔失敗的教室標為「暫時無法恢復」，提示重啟後重試。刪除確認對話框寫明教室名稱及影響，預設焦點在取消，關閉後回到原操作或下一筆。 |
| 教室管理 `/teacher/classrooms/:classroomId` | 共用教師導覽顯示教室名稱、返回清單、管理、分組管理、控制台。主欄按題目來源、題組選擇、備題與標準答案編修排列。側欄先顯示備課就緒條件，再提供「前往控制台」「開啟分組管理」「開啟教室投影」。完成目前收件、審核及 Google 回填後可「開始新活動」，確認時說明保留歷史、沿用分組與換碼。 |
| 分組管理 `/teacher/classrooms/:classroomId/groups` | 先放新增表單，下接組別列。各列顯示組名、學生加入碼、學生名單及「產生投影加入碼」。一次展開一列更名或名單細節，加入碼旁標示用途。名單鎖定時可查看、發放碼，編輯區顯示本場已鎖定與下一場活動可編輯的原因。 |
| 老師控制台 `/teacher/classrooms/:classroomId/console` | 首屏由教室、階段、題組與階段主操作組成。未備題提示前往管理頁，準備完成後顯示「開放搶答」。收件中提供「結束搶答」，主欄呈現題目，側欄呈現送出進度。審核以小組為區段，按小題判對錯，組層級可取消或恢復資格；必要補答在下方。桌面確認區在側欄，窄版放在審核欄位後，提供「確認定案」。頁尾按活動、回合列出已定案答案，展開才查看答案，成果 CSV 及 Google 回填以目前活動為範圍。 |
| 全班投影 `/teacher/classrooms/:classroomId/projection` | 從選定教室的「開啟教室投影」開啟同源唯讀視窗。首列為教室名稱及回合階段，題目佔主要閱讀區，右側為各組收件狀態。畫面僅顯示授權後的投影資料，教師工作區導覽留在原視窗。完成定案後可顯示該回合公布摘要。沒有授權時顯示從登入後的教室管理頁開啟。 |

桌面骨架中的橫線代表段落分界。窄版先呈現左欄內容，控制台首列的階段與收件操作仍在內容前。

```text
我的教室                 教室名稱 ｜ 管理  分組管理  控制台
───────────────────      ───────────────────────────────
建立教室  │ 歷史教室      階段、題組與開放／結束操作
名稱      │ 名稱、時間    ───────────────────────────────
建立教室  │ 恢復／刪除    題目／逐組審核       │ 收件／確認區
                         已定案答案與目前活動成果
```

## 學生端與組別投影

| 狀態 | 畫面與互動 |
| --- | --- |
| 等待 | `/student` 頂部顯示教室與組別。未開放或備題中顯示「等待老師準備題目」。已停止且本組未收件時提示等待公布。 |
| 作答 | 同一路徑依伺服器切換。題組標題後，每小題的題號、完整題幹和答案欄緊鄰。倒數、公平等待限制、校驗錯誤與送答資格用文字提示。「送出本組答案」在最後一題後，以免手機鍵盤遮擋。 |
| 已送出 | 顯示「本組已鎖定送出」，依小題呈現伺服器已接受的答案。收件成功包含同組另一裝置先送出的情況。定案後可接續查看該回合結果，下一回合以新階段取代舊收件狀態。 |
| 組別投影 `/projection` | 獨立裝置先輸入組別投影加入碼，通過後使用全班投影的字體與版面，收件區只顯示該組名稱與狀態。無效、撤銷、過期時清除內容，回到輸入畫面並提示重新取碼。 |

投影的長題幹保留換行並可捲動閱讀，階段和教室／組別保持可辨識。窄視窗題目先於狀態列。未開放題目及未公布答案由後端裁剪，前端直接使用授權後的快照。

```text
手機作答                         全班投影
教室名稱 · 所屬組別              教室名稱                         搶答中
題組標題                         ────────────────────────────────────
小題題幹                         已開放題目               │ 各組收件狀態
答案輸入                         完整題幹                 │ 第一組 已送出
送出本組答案                                              │ 第二組 等待送出
```

- 開啟投影視窗失敗時，在管理頁提示允許該頁開新視窗並提供重試入口。

## 共同狀態與驗收

- 首次載入延續頁面標題與位置。跨教室或活動切換先清除舊資料並取消請求。相同教室及活動內切頁保留對應準備草稿，草稿依題目及版本定位。
- 尚未收到伺服器確認時維持待確認狀態。取得完整快照後，由使用者依收件狀態決定是否手動重試。備課和控制台讀取同一教師分頁的就緒狀態。分組或題目條件未滿足時指出待辦。未儲存的題目草稿在切頁後仍阻止開放，提示「請先儲存題目修改」並提供返回備課入口。伺服器仍驗證已儲存題目、分組及回合狀態。
- 已知該教室正 Google 回填時，暫停「開始新活動」及「刪除教室」。若其他分頁操作競爭而收到 409，顯示「回填進行中，請稍後再試」，保留該教室及活動。回填遇同一張工作表忙碌時，顯示「此工作表正在回填，請稍後再試」，由老師手動重試。
- 更新以可讀文字和適度的 `aria-live` 通知，不逐次朗讀輪詢。錯誤和欄位關聯；送出後輸入區消失時將焦點移至鎖定標題。切換教室或子頁時聚焦標題。導覽標示當前頁，視覺及鍵盤順序一致。
- 審核並行衝突時保留可核對的草稿，提示載入最新狀態。失去權限時清空教室畫面並提供重新登入或回到清單的操作。
- 以 1440、768、360 px、200% 縮放、鍵盤及 1280 × 720 投影驗收。檢查空白清單、長名稱、長題幹、不同答案長度、遠端收件、斷線等候與撤權。詳見 [驗收指南](../quickstart.md)。
