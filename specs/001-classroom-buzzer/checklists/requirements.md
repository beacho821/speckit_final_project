# 規格品質檢核：課堂線上搶答系統

**目的**：確認規格足以規劃本機課堂演練與驗收。  
**建立日期**：2026-11-16  
**功能**：[課堂線上搶答系統規格](../spec.md)

## 內容品質

- [x] CHK001 規格描述可觀察的行為，未指定程式語言、框架或服務介面。
- [x] CHK002 四個情境分別對應備課、課堂作答、公平參與及課後整理。
- [x] CHK003 老師可用實際題號、組別與時間例子核對規則。
- [x] CHK004 使用情境、驗收、需求、主要實體、成功標準及假設均已填寫。

## 需求完整性

- [x] CHK005 無待釐清欄位；公平時段與成功定義已列為假設。
- [x] CHK006 送出資格、平手裁決、題組缺答及回填條件皆有確定結果。
- [x] CHK007 成功標準列明比對份數、同步時限、順位案例及匯出列數。
- [x] CHK008 成功標準可由畫面、原稿與匯出檔驗證。
- [x] CHK009 四個使用情境均有獨立驗收方式及預期結果。
- [x] CHK010 已涵蓋同時收件與結束、重送、位置變更、無人送出及無編輯權。
- [x] CHK011 已界定同機模擬範圍、老師與學生權限及公布時點。
- [x] CHK012 已說明來源存取權、題目辨識約定及同一活動內的公平規則。

## 功能就緒程度

- [x] CHK013 FR-001 至 FR-012 均可透過情境、邊界條件或交付紀錄驗收。
- [x] CHK014 從原稿匯入到原稿回填與全班明細匯出的流程完整。
- [x] CHK015 SC-001 至 SC-005 涵蓋題數、同步、保密、公平與成果核對。
- [x] CHK016 設計圖獨立存放，規格仍以師生操作及可觀察的結果表達需求。

已核對指定範本中的題號與作答欄。混合範本的 4 個主題號對應 6 個填空，驗收時須分別計數。
本表記錄規格審查結果；功能測試須在實作階段執行。
