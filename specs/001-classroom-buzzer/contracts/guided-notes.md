# Guided Notes 匯入與回填契約

## 來源與識別

教師輸入 Google 試算表網址。後端僅解析合法文件 ID 與非負整數 gid（接受查詢參數或片段）；以固定 Google API 呼叫來源，避免直接請求輸入的任意網址。多分頁而未指定 gid 時列出可選分頁，請老師選擇後重送；只有一頁時可自動選取。後續均以同一文件 ID 與 gid 重取，分頁重新排序或更名仍依 ID 尋找。

Drive 匯出的 XLSX 由 ExcelJS 解析。每格以當次讀取的列、欄、合併主格及儲存格內容描述，同步取自 Sheets 的備註與具型別原值補足原稿資訊。兩份視圖的分頁、題號、對應格或值有不一致時，重新讀取或回報「學習單已變更，請重新匯入」，不可部分採用。

| 辨識來源 | 規則 | 範例 |
| --- | --- | --- |
| 表頭與單題 | 在使用範圍內找出同一表頭列的「題號」及「作答」欄，略過標題、分隔空列與純敘述；掃描有題號或可確認子題的各列。空作答格仍算一個填空。 | 單題版為 1～6，共 6 個單位、6 個填空。 |
| 子題標號 | 作答格內單獨的全形或半形括號數字可標示子題。合併的主題號按主格讀取；未合併的延續列只在同一主題區段且有明確子題時沿用。跨空白分隔不得借用上題。 | 混合版單位為 1、2、3、4；完整題號為 1（1）、1（2）、2（1）、2（2）、3、4。 |
| 分散填空標記 | 整格標記「答案：單位名／完整題號」或其識別備註可指出單位及唯一題號。相同單位名一起送出。單位名與題號不得為空或含分隔符號。 | 「答案：運算／5」與「答案：運算／8」無論分布在哪個欄列都必須一起送出。 |

統一子題括號、題號首尾空白後檢查唯一性，顯示時保留可與學習單對照的題號。若有系統寫入的身分備註，以備註辨識該格，答案文字即使形似子題或標記也只算作答內容。其餘格先辨識明確標記，再依表頭關係補足；身分與獨立的表頭／題號線索互相矛盾時，回報歧義。兩個實際格聲稱同一完整題號、兩個單位爭用一格、無法找到作答欄且沒有明確標記、零填空或空題組，全部拒絕。禁止以樣本列欄、題目敘述、檔名或 ExcelJS 分頁序號當作長期對應。

## 寫回原稿

1. 由老師發起。固定本次已結束回合集合，依其勝組紀錄展開「完整題號 → 答案原文」。無勝組的填空不寫入。同一活動只允許一個寫回作業執行。
2. 即時重讀來源分頁的表頭、原始值、備註與合併範圍，使用同一辨識規則重建題號到當前位置的對照。工作表消失、目標缺漏、單位歸屬改變或對應不唯一時，不發寫入請求。
3. 對每個待寫格比對具型別的目前輸入值。與勝組原文字串相同視為已相符；與匯入時的輸入值一致可寫。其餘為衝突，向老師列出全部衝突題號、目前內容與勝組答案。提交前最後一次讀取發現任一衝突即整批零寫入。比較公式本身，不以顯示結果代替。
4. 以單一 Sheets `spreadsheets.batchUpdate` 提交所有目標格的單格 `UpdateCellsRequest`。設定 `userEnteredValue.stringValue`，只更新所需欄位。若用來辨識的子題或標記將被取代，或新答案本身形似標記，在同一請求於目標格既有備註末尾附加一行「課堂搶答：單位名／完整題號」，之後可用該行辨識。保留既有備註文字，重試不可重複附加；其餘普通單題不需改備註。保留版面、合併與格格式，不整列覆寫。
5. 提交後重新讀取原稿，核對題號身分、答案與必要備註。全數相符才回報成功；讀回不符時列出差異題號，或在回應遺失、讀回失敗時列出待核對的目標題號，均顯示「寫回結果待確認」。不得自動重送或回滾。老師重試時從步驟 1 開始重新比對；若已全數相符即結束。批次內的寫入一併生效，前置讀取與提交之間仍可能穿插外部修改，包括遭批次覆寫且無法從讀回偵測的修改。外部共編造成的最後讀寫時間差及服務保證見[研究決策](../research.md)。

## 驗收資料

保留三組獨立預期對照：6 單題、2 題組加 2 單題、移動欄列且使用分散標記的版面。每組都要先比對匯入預覽，再以有辨識度的不同答案回填，重讀原稿核對實際命中位置。混合版在首次回填後再次載入並移動作答欄，仍須找出全部 6 格。另測欄位缺漏、重複題號、合併列、人工改值、無權限與回應遺失。用教師可編輯副本測試真實共享原稿；自動化測試使用相同結構的本機 XLSX 與可控制的 Google 回應。
