# 本機 HTTP 與 CSV 契約

所有路徑均在同一來源的 `/api` 下。JSON 用於資料交換，CSV 端點回傳附件。每次請求（含登入與長輪詢）由分頁用 fetch 顯式設定 HTTP Basic 的 Authorization 標頭，將固定帳號與憑證組成 `teacher:密碼` 或 `student:代碼`，以 UTF-8 轉成位元組後做 Base64 編碼。後端核對對應環境變數，學生另須在目前名單中。教師密碼與任一組別代碼相同即拒絕啟動。憑證只在分頁記憶體短暫使用，禁止置於網址、持久儲存、日誌或回應。受保護回應皆設 `Cache-Control: no-store`。登入失敗不透露有效組名、代碼或教師密碼。老師帳號與 Google 服務帳戶分別用於課堂操作與工作表授權。

| 方法及路徑 | 身分與輸入 | 成功回應與條件 |
| --- | --- | --- |
| POST /sessions | Basic 憑證，空主體。驗證老師或目前名單中的組別。 | 200，回傳公開的 `activityId, role` 與學生自身的 `groupId`。其餘端點都須帶 `X-Activity-Id` 與 Basic 憑證。活動 ID 僅用來拒絕程序重啟前的過期請求，單獨提供不能取得權限。 |
| GET /roster | 老師 | 200，可選的環境組別 ID、顯示名稱及活動名單，省略所有代碼。 |
| PUT /roster | 老師，`{groups:[{id,name}]}` | 200，全量驗證後更新名單；ID 必須在可用環境設定內，ID 與組名皆唯一，首回合開始後回 409。 |
| POST /worksheet/import | 老師，`{url}`，指定 Google 試算表與 gid | 200，來源名稱、主題數、填空數、單位清單與完整題號。連結未指定 gid 且有多頁時，回 200 與候選分頁 ID／名稱，選妥分頁前不更換來源。匯入失敗保留原狀。詳見[學習單契約](guided-notes.md)。 |
| POST /rounds | 老師，`{unitId}` | 201，傳回準備回合 ID 與階段。替換準備中的選題時發新 ID。 |
| POST /rounds/:id/start | 老師，空主體 | 200，階段轉進行中、凍結資格並通知各畫面。 |
| POST /rounds/:id/submissions | 學生，`{answers:[{questionId,text}]}` | 201，僅 `{roundId,received:true}`。拒收保留草稿。組別取自本次驗證結果。 |
| POST /rounds/:id/end | 老師，空主體 | 200，階段轉結束並公布封存結果。 |
| GET /view | 老師或學生，可傳上次收到的 `after` | 200，角色專屬快照及該角色的可見版本。等待上限 20 秒，無變更回 204，再接續等候。 |
| GET /rounds/:id/results | 已登入，指定回合 | 200，已結束時傳回含未送出組的完整明細。進行中的全班快照只供老師；學生不得查詢進行中的結果。 |
| POST /worksheet/writeback | 老師，空主體 | 200，讀回核對成功後傳回已寫入、已相符與無勝組的題號。作用範圍為請求開始時已結束的回合；無已結束者回 409。 |
| GET /results.csv | 老師 | 200，下載請求開始時所有已結束回合的 CSV。無已結束回合時回 409。 |

### 狀態同步

首次 GET /view 立即回應；缺席或斷線後重新取得完整快照。每個分頁一次只掛一個請求。比對版本與登記等候在同一同步步驟中完成，已過期的版本直接取最新快照。中斷時清除等候，重連失敗呈現「連線中斷，正在重新連線」。角色撤權時也須中止該組仍在等待的請求。憑證失效或活動 ID 過期時清除分頁登入狀態，回登入入口。

共通欄位含 `phase, roundId, unit, closedRoundIds`，無準備回合時 `roundId,unit` 為空。學生專屬欄位為 `groupId, received, ownAnswers, waitRemainingMs`，倒數由分頁顯示、後端核對。教師快照另含 `availableUnits: [{unitId, questionIds}]`，依原稿順序列出尚未開啟的單位，含可改選的準備中單位；未匯入或全部用完時為空陣列。學生快照省略此欄。老師取得全班組名、各組收件狀態、已收原文及順位。已結束回合結果包含每個填空與每個名單組別一列。快照只在該身分可見的事件發生時改版；他組送出不喚醒等待中的學生請求。拒絕學生送出時也不得藉錯誤細節透露他組狀態。

### 錯誤

統一結構 `{code,message,details?}`；`message` 以正體中文提供原因與修正方式。`details` 按身分提供缺答或衝突題號。範例：`{"code":"MISSING_ANSWER","message":"第 1（2）題仍未作答，請填妥後一起送出。"}`。拒絕的操作不得耗用順位或改變活動資料。回填已提交而結果待確認時，介面須保留「可能已寫入」的狀態，不可當作整批零寫入。

| HTTP 狀態 | 情況 |
| --- | --- |
| 400／422 | 無效 JSON、連結、無法辨識的工作表、重複題號、缺答或格式不符 |
| 401／403 | 未驗證或憑證失效／身分無權操作。Google 原稿無編輯權時給教師可修正的獨立錯誤碼。 |
| 409 | 公開活動 ID 過期（重新登入）、所處階段不符、名單已鎖、過期回合、延遲未滿、重送或回填衝突。延遲未滿附本組剩餘毫秒數。 |
| 409 | 提交前讀到衝突回 `WRITEBACK_CONFLICT`，整批零寫入。提交後讀回不符回 `WRITEBACK_UNCONFIRMED` 與差異題號，提示老師檢查原稿再試。 |
| 502／503 | Google 連線、暫時限額或服務錯誤。送出後無法確認結果時同用 `WRITEBACK_UNCONFIRMED`，提示重新核對後再試。 |

### CSV 格式

媒體型別為 `text/csv; charset=utf-8`，附件檔名為 `classroom-results.csv`。首列依序為「題號,組別,答案,搶答順位,作答狀態」。依回合、單位內題號、有效順位排序，未送出者接在後面，依名單順序。每個完整題號與名單組別恰有一列；未送出者答案與順位為空。逗號、雙引號或換行以 CSV 雙引號包欄與雙寫引號處理。保留簡答原文，包括前導等號；用試算表驗收時將答案欄當作文字匯入。
