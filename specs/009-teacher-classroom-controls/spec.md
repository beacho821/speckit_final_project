# 教師帳號與課堂操作

2026-11-28 確認需求。本期沿用教室、名單、題庫、回合及輸出模組。

## 使用情境與驗收

| 需求 | 操作與成功條件 |
| --- | --- |
| FR-001 教師登入 | 教室清單與教室內頁左下角顯示教師頭貼與姓名，點選後開啟帳號設定。未設定姓名時顯示帳號。主帳號可建立子帳號。子帳號更換自己的密碼時須通過目前密碼驗證，驗證失敗保留原密碼及登入，成功後所有原登入失效。兩名教師各建一間教室，其清單、操作、歷史、投影與輸出只限本人。既有教室歸主帳號。 |
| FR-002 學生名單 | 名單鎖定前可移組，已登入學生留在原頁並切換至新組別，重新整理仍可接續。移除學生則撤銷身分。目的組同名時拒絕移組。可下載及匯入只有「組別」「名字」的 XLSX 名單，名字可含座號。匯入合併既有名單，檔內同組同名或格式錯誤須指出問題並整批取消。 |
| FR-003 選填標準答案 | 有題幹即可儲存並開題。已提交而缺標準答案的作答須人工判分，老師可判正確或錯誤。 |
| FR-004 AI 備題 | 匯入預覽、手動新增及編修單題或題組共用 AI 建議視窗。只對有題幹且標準答案空白的勾選小題產生建議，教師確認後將主要及其他可接受答案逐行填入草稿。已有答案的小題保留原文，可略過或重試失敗的小題。 |
| FR-005 動態冷卻 | 同活動取最近五個已定案題組，不足五組就取現有紀錄。各組 p 為最終答對小題數除以所有小題數，未答及失格計零。上一題得標等 T = 5 + 3p² 秒，上上題得標等 0.6 × T 秒，兩者取長，其餘立即開放。無人得標也佔一題。老師與投影顯示各組狀態和剩餘秒數，學生在倒數時可讀題，所有小題輸入框和送出按鈕於期滿時一併開放。以伺服器收到送答的時間判定，提早提交不佔順位。 |
| FR-006 補答 | 定案前逐題選擇留白、使用標準答案或輸入補答。Google 回填及本機 XLSX 副本呈現相同選擇，保護來源、既有定案與原有勝組計分。 |

回填勝組答案或教師補答時，若作答表頭下方分為小題編號與答案兩欄，保留左欄編號，將答案填入同列右欄。單題若橫向合併作答格，將答案填入合併格並保留其範圍。

FR-002 的新增組別與 Excel 名單匯入在開題後仍可使用。手動新增及匯入產生的新組可參加仍在收件的回合；停止收件後才新增的組別從下一題參與。教師分頁自動取得名單更新。已公布的頒獎名次保留公布當時的組別。

## 邊界與成功標準

跨帳號讀寫成功數為零。無標答且無人送答時可直接定案。已提交待人工判分者須完成審核。上一題與上上題得標組的答對率同為 50% 時分別等待 5.75 與 3.45 秒，100% 時分別等待 8 與 4.8 秒。補答不計入組別得分。既有回合保留歷史補答規則。
