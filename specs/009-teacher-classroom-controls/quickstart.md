# 課堂操作驗收

1. 在本機環境設定主教師帳號、密碼。登入後由左下角頭貼建立兩位教師，分別驗證有填姓名與沿用帳號的顯示方式。各登入並建立教室，核對清單與歷史。在教室內開啟帳號設定，先輸入錯誤的目前密碼，確認仍可使用原登入，再輸入正確的目前密碼與新密碼，確認須重新登入且原教室仍可開啟。
2. 下載組別名單 Excel 範例並匯入，確認同組兩位同名學生用座號區分。再匯入一次，核對新增人數為零。在另一分頁以完整名字加入，教師移組後核對該分頁組名、即時排名與重新整理後的組別。刪除該成員，確認分頁登出。
3. 預覽含多個小題的 XLSX 或 Google 題源。先手填一個小題的標準答案，再開啟 AI 建議視窗，確認只列出有題幹且尚未填答的小題。勾選其中一題產生建議，核對主要與其他可接受答案後填入，另一題可留白。確認入列後，用鉛筆編修題組，檢查各小題的答案及儲存結果。
4. 開放學生提交，結束後核對有標答的自動判分，並替缺標答的作答判分。對兩個無人答對的子題，各選補答與留白，確認定案。
5. 在結算頁回填授權的 Google 教師副本，或提供原 XLSX 下載副本，核對填入的答案、空白格及其他工作表。
6. 讓甲乙兩組依序得標且各答對半數小題，驗證下一題甲等待 3.45 秒、乙等待 5.75 秒，其餘組可直接提交。若同一組連續得標且全對，驗證只等待 8 秒。核對教師與投影的各組狀態，並確認學生在倒數期間可閱讀題目；所有小題輸入框與送出按鈕都應於歸零時開放。

HTTP 案例需可連線到本機暫時連接埠。AI 與 Google 可透過測試替身重跑。重啟存檔驗收使用獨立暫存資料夾。

## 重跑 Edge 驗收

在專案根目錄先建置，再以暫存工具目錄啟動測試。需已安裝 Microsoft Edge。腳本使用記憶體教室、隨機密碼及模擬 AI。

```powershell
npm run build
$browserTools = Join-Path $env:TEMP "ofinal-009-browser-tools"
npm install --prefix $browserTools --ignore-scripts --no-save --package-lock=false playwright-core@1.56.1
node scripts/verify-teacher-controls.mjs $browserTools
node scripts/verify-cooldown-browser.mjs $browserTools
```
