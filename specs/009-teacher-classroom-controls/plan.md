# 實作計畫

沿用 React 教師工作區、Express 活動授權、每教室寫入佇列及本機原子存檔。依組件圖、類別圖、時序圖沿用團隊既有功能邊界。

| 模組 | 本期介面與資料 |
| --- | --- |
| 登入與教室 | 主帳號由環境讀取。子帳號使用獨立識別與加鹽密碼雜湊。教師工作區登入後使用分頁記憶體權杖。教室存檔新增擁有者，舊存檔歸主帳號。 |
| 教師帳號設定 | 登入回應附上顯示姓名，舊帳號沿用帳號名稱。教室清單與內頁共用頭貼入口與設定對話框。子帳號改密時，後端在同一筆序列化寫入中驗證目前密碼，存檔成功後撤銷該帳號的登入。 |
| 名單 | 移組保留成員識別。加入時簽發限本場本人的分頁憑證。舊分頁可用本場已驗證的加入碼與本人識別接續登入，移組後一律從目前名單取得所屬組別。刪除成員時一併撤銷舊登入紀錄。分組管理沿用現有 XLSX 函式庫及教室寫入佇列，一次合併通過驗證的名單。 |
| 題庫 | 匯入分頁先在記憶體暫存預覽，以題庫版本與匯入世代確認。單題與題組共用 AI 建議視窗，逐題沿用建議 API。題組請求附指定小題，採用時再次比對題幹及答案空白狀態。教師以既有匯入及整卡儲存流程保存草稿。 |
| 回合 | 開題時凍結標準答案與每組送答時間。缺少標答的作答待判，公布時一次驗證審核版本、判分與補答選擇。 |
| 學習單 | Google 與 XLSX 共用依題號比對的回填計畫。XLSX 重新選原檔並比對匯入指紋，只供下載結果副本。舊版回合維持既有封存與回填規則。 |

驗收涵蓋不同教師、過期身分、空白標答、AI 失敗、冷卻時間邊界、老師勾選與留白、學習單衝突及既有課堂流程。
