# 資料模型｜搶答題目與判分

對應 [類別圖](../../diagrams/003-class.puml)與[時序圖](../../diagrams/003-sequence.puml)。欄位名稱為規劃用識別字。

## 課堂活動與題庫

| 資料 | 欄位與關係 | 驗證及生命週期 |
| --- | --- | --- |
| 課堂活動 | 既有活動、組別、成員、角色版本、來源、匯入世代、回合；新增活動題庫 | 記憶體隨程序重啟重建。名單及匯入鎖定沿用首回合成功開題的時點。 |
| 搶答單位 | 活動內 `unitId`、名稱、依原順序排列的題目鍵 | 每單位至少一題。手動單位只有一題。每單位至多一個已開始的回合。 |
| 題目 | `questionKey`、`questionId`、單位、`prompt`、`origin`、`acceptedAnswers`、`questionRevision`；匯入題另有對應 `fillBlankId` | 完整題號去除頭尾空白後在活動內唯一。題幹保留原可見文字及換行。缺題幹的匯入題將 `prompt` 設為空值；手動題不可空白或僅重複題號。判定題號佔位時忽略頭尾空白與題號後單個句點（如「1.」），並以完整題號核對。活動題目鍵在來源替換時更新，與原稿填空身分分離。 |
| 標準答案 | 每個題目零或多個已清除行首尾空白的非空文字，僅老師可見 | 備課可暫缺，開題時每題至少一種。拆分 LF、CRLF 或 CR，略過空白行。比對完整學生答案的去頭尾空白值，使用區分大小寫的逐字等值比對。原始送答不變。 |
| 原稿位置 | 既有 `Worksheet.source`、`FillBlank`、題組識別、座標、原值／型別與備註 | 原稿位於來源工作表。工作台編輯題幹、標準答案或手動新增題目只改活動題庫。原稿重新辨識維持既有填空與題組比對。 |

匯入只在既有驗證及活動世代檢查通過後提交。提交前再次檢查目前手動題的完整題號，成功才替換來源及其匯入題、清除準備回合並保留手動題及名單。辨識題幹時避開題號、作答及用於標記身分的填空格；題幹欄本身也排除於填空標記掃描。共用題幹只取同一題組中明確由題幹合併範圍覆蓋的子題。辨識題幹失敗本身不使舊來源失去可匯入性。

## 回合與作答紀錄

| 資料 | 欄位與關係 | 驗證及生命週期 |
| --- | --- | --- |
| 回合 | `id`、`unitId`、`phase`、既有名單與開放時間；開題時固定有序題目副本（題號、題幹、來源關係、私有標準答案）；待確認判分時維護 `reviewRevision` | 未成功開題的回合沿用可編輯題庫。只有當前回合可收件、停止收件及儲存草稿。 |
| 組別送答 | 既有組別、收件時間、不變的 `rank`、完整題號對應的答案原文 | 每組每回合一筆，必須答完所有子題。沿用等待與接受順序。 |
| 判分 | 每筆已收答案一個 `autoCorrect: boolean`，可有 `overrideCorrect: boolean`，以 `overrideCorrect ?? autoCorrect` 取得最終正誤 | 停止收件時填入初判。待確認判分時，老師只可改已有收件的組別與對應完整題號。保留原文及順位。 |
| 老師補答 | 依回合及完整題號對應的文字草稿，公布後形成結果 | 對某題存在最終答對紀錄時移除該題補答草稿。若之後改回無人答對，重新提示填寫。所有無人答對的題目須有非空補答才能公布。 |
| 已公布結果 | 固定題目、各組原文與最終正誤、老師補答、可空的 `winnerGroupId` | 用原順位找第一個整個單位全對的組別；無人全對時為空。相同回合再次公布只回傳既有結果。 |

## 階段與資料提交

| 轉移 | 觸發與條件 | 可觀察結果 |
| --- | --- | --- |
| 無回合 → `preparing` | 老師選取未使用單位 | 選題可改，老師可儲存題幹及標準答案。 |
| `preparing` → `active` | 當前回合、名單非空，每個子題的題幹及標準答案均完整 | 固定題目副本及名單。學生同步取得題幹並受本組開放時間約束。 |
| `active` → `reviewing` | 老師停止收件 | 已接受答案全部計入並完成初判。學生保持本組收件狀態且無法再送答。 |
| `reviewing` → `ended` | 複核版本相符且必填補答齊全 | 單次提交最終結果、教師補答及勝組。更新歷史、匯出、回填及公平等待的資料來源。 |

每次異動先驗證完整輸入與當前資料，再同步提交。老師端題目、判分草稿用各自的版本欄位防止舊分頁覆蓋。題目清單、標準答案或複核草稿的教師私有變更只推進教師視圖版本。開題、停止收件及公布推進所有可見角色版本。
