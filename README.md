# 課堂活動

老師可建立多間教室，分別備課、分組、主持搶答、審核及投影。學生用加入碼與名稱進入對應教室，同組共用每回合首次有效送答與順位。每間教室的分組、成員、題目與歷史紀錄自動存入專案根目錄的 `classroom-data/`。

## 本機開發

需要 Node.js 22.12 以上與 npm。在專案根目錄執行：

```sh
npm ci
cp -n .env.example .env
# 使用編輯器在 .env 設定 TEACHER_PASSWORD
npm run dev
```

單一 `npm run dev` 同時啟動 API 與 Vite，開啟終端顯示的位址（預設 [http://127.0.0.1:5173](http://127.0.0.1:5173)）。啟動會讀取根目錄 `.env`，外部環境變數優先；`PORT` 控制 API，預設 3000，可設為 1–65535。前端可用 `npm run dev -- --port 5174` 更換連接埠。

Ctrl+C 關閉兩個服務。前端熱更新不重設活動；修改後端或 `.env` 後，重新執行指令才生效。重新啟動會自動載入教室。若上次仍在收件，回合轉為待審核，原答案及順位保留。`.env` 不納入版本控制，教師密碼與 Google 金鑰也不會存入瀏覽器儲存區。

## 使用流程

1. 老師登入後從「我的教室」建立教室，或選「恢復主持」繼續既有活動。進入教室會先開啟「分組管理」，每間教室可獨立進行搶答。
2. 在「分組管理」新增組別，點擊學生加入碼即可複製並分發。學生以加入碼和名稱進入教室。
3. 在「題目管理」匯入本機 XLSX（上限 10 MiB）或 Google 試算表，所有題目會自動排入出題清單。用鉛筆圖示編修題幹與答案，按「儲存修改」一次儲存整張題卡。拖曳卡片頂端的長條把手或使用箭頭圖示可調整出題順序。手動題排在末端。
4. 到「老師控制台」開放下一題。題號依實際開放順序編定。首回合開始後，當次活動的分組與來源鎖定。老師結束收件後可改判、取消或恢復資格及補答，再確認定案。定案後，學生的作答畫面會逐題顯示正確或錯誤。
5. 從教師導覽右側的「開啟教室投影」開啟全班投影。偵測到斷線時，投影標示重新連線並保留最後畫面最多 10 秒。學生用導覽切換作答與本組已公布的歷史紀錄。
6. 控制台可查歷次定案結果。完成進行中的回合與審核後，按「結算」可預覽最終排名、回填、下載目前活動的 CSV、公布結算或開始新活動。按「公布結算」後，教室投影與學生端會突出顯示前三名，直到老師開放下一題或開始新活動。「開始新活動」沿用分組和出題順序，舊答案仍保留，積分從零開始。刪除教室前會顯示受影響的紀錄。

每次定案後，學生端與教室投影會同步更新積分與名次。單題答對得 1 分，答對組別中最快及第二快另得 2 分及 1 分。題組每答對一小題得 1 分，速度加分只發給答對最多小題的組別中最早送出的兩組，每組每回合最多獲得一次速度加分。取消資格、未送出或全錯的組別該回合得 0 分。總分相同時並列，並列前三名的組別一併顯示。

學生身分僅暫存在該分頁的 `sessionStorage`。重新整理先向伺服器驗證，斷線後重新取得課堂狀態。活動失效、登出或撤權後清除暫存。開始新活動或重啟伺服器後，請重新分發學生加入碼。

首次匯入保留手動題。首題開放前可確認重新匯入，成功後清除原有卡片與清單，包含手動題。取消或失敗則保留原資料。匯入結果待確認時，請等待同步後再操作。

Google 功能另需在 `.env` 提供 `GOOGLE_SERVICE_ACCOUNT_JSON`（服務帳戶 JSON 檔案路徑，可使用相對於專案根目錄的路徑），並分享工作表給該服務帳戶。讀取用檢視權限，回填需編輯權限；建議使用獨立教師副本。純本機 XLSX 不需 Google 設定。同一張工作表一次處理一筆回填。若工作表忙碌，請等待後手動重試。

## 建置與驗證

```sh
npm run typecheck
npm test
npm run build
npm start
```

建置後的 `npm start` 在 [http://127.0.0.1:3000](http://127.0.0.1:3000)（或設定的 PORT）供應前端與 API。HTTP 測試需要可監聽本機暫時連接埠。

需要從區網的學生裝置或教師投影測試時，先停止開發服務，再執行 `npm run build` 與 `HOST=0.0.0.0 npm start`。使用伺服器的區網位址及指定連接埠。

參考 [教室驗收指南](specs/004-redesign-classroom-ui/quickstart.md) 及 [實作驗證紀錄](specs/004-redesign-classroom-ui/validation-results.md)。
