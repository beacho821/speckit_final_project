# 課堂活動

老師建立組別與加入碼、匯入學習單並主持搶答。學生用加入碼和名稱加入，同組共用每回合首次有效送答與順位。資料保存在目前伺服器活動的記憶體，停止後不保存。

## 本機開發

需要 Node.js 22.12 以上與 npm。在專案根目錄執行：

```sh
npm ci
cp -n .env.example .env
# 使用編輯器在 .env 設定 TEACHER_PASSWORD
npm run dev
```

單一 `npm run dev` 同時啟動 API 與 Vite，開啟終端顯示的位址（預設 [http://127.0.0.1:5173](http://127.0.0.1:5173)）。啟動會讀取根目錄 `.env`，外部環境變數優先；`PORT` 控制 API，預設 3000，可設為 1–65535。前端可用 `npm run dev -- --port 5174` 更換連接埠。

Ctrl+C 關閉兩個服務。前端熱更新不重設活動；修改後端或 `.env` 後，重新執行指令才生效，並開始空白新活動。`.env` 不納入版本控制，教師密碼與 Google 金鑰也不會存入瀏覽器儲存區。

## 使用流程

1. 老師以教師密碼登入，輸入組名新增組別，再將畫面上的加入碼提供給該組學生。可於首回合前更名或刪組；不使用環境預設組別。
2. 每個學生分頁選擇學生，填加入碼與名稱。名稱及組名去除頭尾空白後限 1–40 個可見字元。老師名單顯示本活動曾加入的名稱，登出／斷線不移除；同組同名重連沿用原成員。
3. 選擇本機 `.xlsx`（最多 10 MiB），或提供有讀取權限的 Google 試算表網址。多張可辨識工作表時先明選分頁。確認題號與題組預覽，選題、準備，再開始回合。
4. 首回合開始後，整堂活動的名單與來源都會鎖定；既有組仍可讓學生晚加入。每組整份題組一次送出；下一回合上一勝組須等待 3 秒，其他組可先送出。
5. 結束回合公布結果，可下載整堂活動 CSV。本機 XLSX 不支援回填原檔；Google 來源可將勝組答案回填，會先核對題號與原值，任一衝突則整批拒絕，提交後讀回確認。

學生本人身分僅暫存該分頁的 `sessionStorage`；重新整理先向伺服器驗證。斷線後取得完整現況，不會自動重送答案。登出、已知撤權或活動過期會清除暫存。刪組立即撤銷加入碼，重建同名組會取得新碼；程序重啟使全部舊碼與活動失效。

首回合前成功換學習單會清除舊選題／準備回合，保留組別及成員。若匯入回應遺失，畫面顯示「匯入結果待確認」，同步目前快照後才恢復匯入與開題，不自動重送匯入。

Google 功能另需在 `.env` 提供 `GOOGLE_SERVICE_ACCOUNT_JSON`（服務帳戶 JSON 檔案路徑，可使用相對於專案根目錄的路徑），並分享工作表給該服務帳戶。讀取用檢視權限，回填需編輯權限；建議使用獨立教師副本。純本機 XLSX 不需 Google 設定。

## 建置與驗證

```sh
npm run typecheck
npm test
npm run build
npm start
```

建置後的 `npm start` 在 [http://127.0.0.1:3000](http://127.0.0.1:3000)（或設定的 PORT）供應前端與 API。HTTP 測試需要可監聽本機暫時連接埠。
